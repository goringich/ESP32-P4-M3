# BOM — сферический робот

Числовой source of truth для геометрии и текущих предположений — `config/dimensions.json`.
Требования к моменту привода нельзя копировать вручную из этой таблицы: перед выбором мотор-редуктора запускать
`python mechanical/spherical_robot/calculations.py --json` и использовать
`pendulum.minimum_continuous_drive_torque_nm` и `pendulum.minimum_short_drive_torque_nm`.
Они рассчитываются по худшей разрешённой комбинации ballast/radius, а не по номинальной конфигурации.

| Позиция | Кол-во | Требование |
|---|---:|---|
| DC/BLDC мотор-редуктор маятника с энкодером | 1 | Реальная torque-speed curve должна закрывать расчётный continuous/short torque из `calculations.py`; целевая выходная скорость задаётся `target_pendulum_output_rpm`; напряжение по батарее; рабочий ток и stall current подтверждаются datasheet/bench test; металлический выходной вал; энкодер с достаточным разрешением на низкой скорости |
| Рулевой привод | 1 | Рабочий диапазон должен закрывать `steering_limit_deg`; удерживающий/самотормозящий редуктор предпочтителен; обязательна обратная связь угла; съёмный выходной элемент |
| Радиальные подшипники вала | 2 | Текущий envelope хранится в `bearing_size_mm_PLACEHOLDER`; одинаковая серия; закрытые; окончательная посадка только после bearing coupon |
| Стальной вал | 1 | Диаметр и длина берутся из `shaft_diameter_mm` / `shaft_length_mm`; прямой, шлифованный; фактический допуск и биение измерить |
| Магнитный или оптический энкодер маятника | 1 | Статор на steering frame, ротор/магнит на валу; провода не вращаются; частота/разрешение должны обеспечивать control period |
| ESP32-P4-M3 | 1 | Существующая плата; измерить envelope, монтажные отверстия и keepout разъёмов до финальной печати tray |
| MPU-9250 module | 1 | Жёсткая фиксация на неподвижном каркасе; ориентация должна быть зафиксирована в firmware coordinate contract |
| Аккумулятор с BMS | 1 | Envelope и масса берутся из canonical config до замены на MEASURED/DATASHEET; continuous discharge должен иметь запас относительно реального motor current; обязательна доступность аварийного отключения |
| Силовой driver | 1 | Напряжение батареи; continuous/peak current выбранного двигателя; защита от выбросов и перегрева; реальный envelope измерить |
| Главный выключатель | 1 | Размыкает питание силового привода; cutout и допустимую толщину панели измерить |
| Зарядный разъём | 1 | Ток/напряжение по батарее и заряднику; механическая фиксация к люку; зарядка внутри закрытого шара запрещена до thermal/BMS validation |
| Стальной балласт | 1 комплект | Варианты массы задаются `ballast_variants_g`; фактическую массу каждого пакета измерить; пластик в массу балласта не засчитывается |
| M3 винты с утопленной головкой | ориентир 36 | Панели, люк и съёмные узлы; длины подобрать после validation heat inserts |
| Латунные термовставки M3 | ориентир 24 | Фактический диаметр/длина и pilot hole измерить; сначала `HEAT_INSERT_TEMPLATE` |
| M3 гайки/Nyloc и шайбы | ориентир 20 | Ступица, балласт, mounts, оснастка |
| M2/M2.5 крепёж | по факту плат | Только после измерения отверстий плат |
| Ремень аккумулятора | 1–2 | Ширину и толщину измерить; не пережимать ячейки |
| Проводка, гибкая оплётка, разъёмы | комплект | Закрепить на fixed frame; ни один провод не проходит через вращающийся маятник; силовые и sensor-линии разводить раздельно |
| TPU 95A | комплект inserts | Сменные распределённые элементы сцепления; геометрия определяется canonical CAD |

## Gate перед закупкой и установкой привода

1. Запустить sizing report и зафиксировать worst-case ballast/radius.
2. Выбрать конкретный motor/gearbox/encoder и сохранить datasheet.
3. Заменить соответствующие `*_PLACEHOLDER` значения на DATASHEET/MEASURED.
4. На стенде измерить no-load speed/current, рабочий ток, stall current через ограниченный источник, нагрев и доступный момент.
5. Повторить analytical + multibody + controller-in-loop evidence с реальными параметрами.

Расчётные требования не заменяют bench test и не дают `physical_accepted=true`.
